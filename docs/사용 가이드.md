## 전체 흐름

**합성 계획**(계산·카드 인쇄) → **합성 기록**(lot DB) → **ICP 분석**(peak 추천 → 준비 → 결과 가져오기) → **ICP 기록**(조성·수율 DB) → **엑셀 내보내기**.

상단 칩이 "클라우드 동기화 중"이면 모든 변경이 자동 저장·동기화됩니다("로컬 저장"이면 이 브라우저에만 기록 — 로그인하면 전체가 올라갑니다).

## 합성 계획

화면 맨 위에서 **Core 합성 / Shell 성장**을 고릅니다. 아래 구조는 두 모드가 같습니다.

```
레시피 줄            ← 통째로 저장·불러오기
계획 메인            ← 항상 펼쳐져 있음 (샘플명·날짜·목표·성분표)
▶ 검증               ← 접이식. 문제가 있으면 자동으로 펼쳐집니다
▶ 합성 프로세스       ← 접이식
▶ 용매/시약 조건      ← 접이식 (Shell은 Shell-precursor solution)
```

접이식 섹션은 접혀 있어도 **머리줄에 요약**이 보입니다(예: `6단계 · 140 도 50 분 › 110 도 30 분 …`). 접힘 상태는 기억되지만, **검증에 문제가 있으면 접힘 설정과 무관하게 펼쳐집니다** — 문제를 접어서 숨길 수 없습니다.

### 성분표 — 조성을 그대로 적는다

역할·원소·개수에 제한이 없습니다. 행을 추가·삭제하고 ↑↓로 순서를 바꿔 원하는 조성을 그대로 표현합니다.

| 칸 | 뜻 |
|---|---|
| **역할** | Host cation · Dopant · Host anion · 첨가제 · 기타 |
| **원소** | 주기율표에서 선택 |
| **Precursor** | 그 원소의 전구체 (물질 DB에서 선택) |
| **투입량** | 아래 네 가지 방식 중 하나 |
| **mmol / Wel / Wprec** | 계산 결과 — 전구체 mmol, 원소 무게, 전구체 칭량 |

**투입량을 정하는 네 가지 방식** — 성분마다 따로 고를 수 있습니다.

| 방식 | 언제 쓰나 |
|---|---|
| **조성비 × 목표** | 보통. 계수 × 목표 mmol. 과량은 `×` 칸에 따로 적습니다 |
| **전구체 mmol** | 그 전구체를 몇 mmol 넣을지 직접 정할 때 |
| **질량 mg** | 저울 눈금으로 정할 때 |
| **다른 성분의 배수** | "Ln 총량의 2.5배"처럼 다른 행에 매다는 경우 |

> **과량은 몰비·무게에만 반영되고, 조성 기록에는 계수 그대로 저장됩니다.** Na를 2.5× 넣어도 기록되는 조성식은 Na 1입니다.

### 검증 — 무엇을 확인하는가

기준은 **위에 입력한 조성에서 자동으로 유도**됩니다. 따로 설정할 것이 없습니다.

- **조성 계수 합 (dopant)** — dopant 계수의 합이 1인가
- **전구체 화학식** — 모든 성분의 전구체 화학식이 물질 DB에 있는가
- **전구체 지정** — 빠진 성분이 없는가
- **원소 수지 표** — 원소별 `필요 [mmol] = 조성계수 × 목표` 대비 `실제 [mmol] = 필요 × 그 행의 과량`, 그리고 비율(`2.50× 과량` / `1.00× 화학량론` / `0.90× 부족`)

Shell 모드에서는 여기에 **기하가 요구하는 양 대비 주입으로 실제 들어가는 양**이 더해집니다. 주입량 계산이 불가능하면 실제·비율 칸을 비우고 그 사실을 따로 표시합니다 — **계산이 안 되는 상태를 초록색으로 넘기지 않습니다.**

### 레시피 — 계획을 통째로 저장

성분·전구체·투입방식·절차(블록 구성·시약 mL·전구체 표시)를 **한 덩어리로** 저장합니다. 같은 조성이라도 사람마다 다른 부분이 그대로 재현됩니다.

| 버튼 | 하는 일 |
|---|---|
| **저장** | 지금 고른 레시피에 현재 계획을 덮어씁니다 |
| **새 이름으로** | 현재 계획을 새 레시피로 |
| **삭제 / 내보내기 / 가져오기** | 삭제 · JSON 파일로 주고받기 |

**랩 공용 레시피** — 설정 탭에서 **랩 ID**를 넣으면 목록에 `랩 공용` 묶음이 생깁니다.

- **[랩에 올리기]** — 내 레시피를 랩 전원이 볼 수 있게 올립니다(올린 사람 이름이 함께 표시)
- 랩 공용 레시피는 **직접 고칠 수 없습니다**(저장·삭제 잠김) — **[내 것으로 복사]** 후 편집하세요
- **[랩에서 내리기]** — 올린 사람만 내릴 수 있고, 내 사본은 남습니다
- 개인 실험 기록은 공유되지 않습니다. 레시피만 함께 씁니다

설정 탭의 **[랩 공유 가이드]** 버튼에 관리자·멤버가 각각 무엇을 해야 하는지 화면 그대로 적혀 있습니다.

### Shell 성장

**source lot**을 고르면 잔량이 자동 추정됩니다. Aliquot (v) mL을 넣으면 core-trace (n)이 비례 계산됩니다.

**Source radius (R)** · **Target thickness (T)** → 셸 부피 `L = (4/3)π((R+T)³ − R³)` 로 필요 물질량과 용액 사용량이 나옵니다. source lot에 TEM 반지름이 저장되어 있으면 R이 자동으로 채워집니다.

**Shell-precursor solution** 섹션에서 용액의 성분을 자유롭게 구성합니다(용질 / 보조). 주입 단계(μL)는 고정 목록으로 적고 마지막 단계는 자동으로 나머지가 됩니다.

> Na-TFA는 **Methanol 1.5 mL에 미리 분산**한 뒤 첨가합니다(용해도와 제거 시간의 균형점 — 값은 계획 화면에서 조정).

## 합성 프로세스 · 시약 (v1.6.0~)

절차(블록 구성)는 **레시피**에 함께 저장됩니다. 예전의 '프로토콜'은 없어졌고, 쓰던 프로토콜은 **'[절차] 이름' 레시피**로 옮겨졌습니다 — 고르면 **성분은 그대로 두고 절차만** 불러옵니다. 새 계획을 특정 레시피의 절차로 시작하려면 레시피 칸의 **[☆ 기본 절차로]**.

**블록 편집기** — 계획 화면 **합성 프로세스** 섹션(또는 [전체 프로세스 편집…]).

- 팔레트에서 블록(열처리·진공·퍼지·시약 첨가·시료 주입·메모) 추가 → 블록 **클릭** → 왼쪽에서 상세 편집
- 카드는 **가로 3칸 격자**입니다. 점선 칸이 놓을 수 있는 자리 — 블록을 **끌어 빈칸에** 놓고, **오른쪽 아래 손잡이**로 가로 1~3칸·세로 1~6칸. **다른 블록은 움직이지 않으며**, 겹치는 자리는 빨갛게 표시되고 놓이지 않습니다
- 블록 상세의 **칸 배치(열·행·가로·세로)**로 정확히 지정할 수도 있습니다. 예: 왼쪽 세로 1×2 = 열1·행1·가로1·세로2, 오른쪽 2×1 두 개 = 열2·행1·가로2·세로1 / 열2·행2·가로2·세로1
- 카드 밖으로 끌면 삭제(알림의 [되돌리기]로 복구)

**시약(용매)은 블록에 mL로 직접** — 블록 상세의 '시약' 칸에 이름과 mL를 적습니다(+ Oleic acid 같은 버튼으로 이름 빠른 입력). 카드 왼쪽 '시약' 표에는 **넣는 순서대로, 합치지 않고** 나옵니다(예: Oleic acid 2 mL → Methanol 3 mL → Oleic acid 3 mL).

**전구체 표시** — 시약 첨가 / 시료 주입 블록에서 **Ln · Na · 음이온**을 체크하면 카드의 그 칸에 해당 전구체 이름·mg가 나옵니다(체크 안 하면 표시 없음). 전구체 전체 칭량표는 항상 카드 왼쪽에 있습니다.

**🧮 시약 계산기 (필요할 때만)** — 계획의 '시약 (절차 순서)' 섹션이나 블록 상세에서 엽니다. 계산식 기준값:

| 항목 | 계산 |
|---|---|
| Oleic acid | 목표 × 10 mL (소수1 반올림) |
| 1-Octadecene | 총량(≤1 mmol이면 10, 초과면 20) − Oleic acid |
| Oleyl amine | 목표 × 당량의 몰수 → 순액 부피 (M.W.·밀도 입력) |
| Methanol | 음이온 전구체 칭량 mg × 0.05 후 정수 올림 |

값을 고쳐 보고 [넣기]/[모두 넣기]로 원하는 블록에 넣습니다(같은 블록·같은 이름이면 값만 교체). 넣은 뒤에는 블록 값이 기준입니다.

**예전 방식으로 저장된 기록** — 저장된 lot 카드는 저장 당시 모습 그대로입니다. 그 lot이나 옛 레시피를 계획에 열면 당시 계산값이 블록에 자동으로 옮겨지고 안내가 뜹니다 — 넣은 위치가 맞는지 확인하세요(Methanol은 첨가 블록이 있으면 그쪽, 없으면 첫 블록).

**Print Preview 카드** — 전구체·시약 왼쪽 / 절차 오른쪽 2열. **카드 형식**: 자동(좁은 절차 칸에 전구체·시약이 들어가면 A4 가로 전폭) / 세로 반장(A4 세로 1/4, 한 장에 2열) / 가로 전폭(A4 가로, 한 장에 위아래 2개). 가로 전폭은 화면에선 축소돼 보이니 [크게 보기]로 확인·수정하세요. 카드 칸을 **클릭해 직접 수정**할 수 있고(Reset Edits로 초기화), **Save as Lot N**으로 기록에 저장합니다.

> 유기용매는 모두 풀네임으로 표기합니다: **Oleic acid · 1-Octadecene · Oleyl amine · Methanol**

## 합성 기록

표의 값 의미: **Stock [mmol]** = core-trace(입자들이 코어로 합성될 때의 양이온 mmol — 계보 비례 추적값) · **Core-trace 농도** = 그 값 ÷ stock 부피 · **물질량 AB** = 누적 stoichiometric 총량 · **몰농도 AC = AB ÷ 부피 ← ICP 기준** · **Group** = 조성에서 자동 생성(원자번호순, Shell 계보는 " @ "로 누적). 검색은 입력 후 **Enter**.

lot을 클릭하면 상세 드로어가 열립니다 — 계보 체인, 잔량, ICP 기록, 그리고 **TEM 반지름 입력**.

반지름을 저장하면 그 자리에서 입자수가 계산됩니다.

```
N = AB × N_A ÷ (입자 하나에 든 Ln 수)
입자 하나에 든 Ln 수 = (4/3)πR³ [nm³] × Ln 밀도
```

**Ln 밀도**는 입자수 바로 아래에서 고칩니다(TEM 반지름이 없으면 쓰이지 않으므로 행 자체가 나오지 않습니다).

> 기본값 **13.85 Ln/nm³** = β-NaLnF₄ 육방정 (a 5.97 Å · c 3.51 Å · Z 1.5) → 1.5 ÷ 108.3 Å³.
> **호스트 격자가 바뀌면 값이 달라집니다** — α-NaYF₄ 입방정은 ≈ 24.4.

**복수 카드 인쇄**: 표 왼쪽 체크박스로 여러 lot을 고른 뒤 **선택 카드 인쇄** — A4 2열로 배치되고 카드 높이를 실측해 페이지가 잘리지 않게 채웁니다.

## ICP 분석

**① Peak 추천** — 원소를 주기율표에서 고르거나 lot에서 불러오면 간섭 DB(166 기준피크) 기반으로 파장을 추천합니다. 배지 = 최악 간섭비(1%/5%/20% 등급). Gaussian On이면 선폭(σ) 겹침을 가중합니다.

**② 샘플 준비** — 선택한 lot들의 stock 채취량·희석 절차를 출력합니다. ICP에 필요한 몰농도는 core-trace가 아니라 **AC(물질량 몰농도)** 기준입니다.

**③ 결과 가져오기** — 파일을 끌어다 놓기·클릭·**Ctrl+V**(파일 또는 복사한 표/텍스트). ICP-OES와 ICP-MS를 자동으로 구분합니다.

| 입력 | 인식 |
|---|---|
| ICP-OES 장비 export(.xlsx) — `Solution Label` + "원소 파장 nm" 열 | ICP-OES |
| Thermo Qtegra 보고서 **PDF**(검정곡선·LoD·표준·샘플 페이지 포함) | ICP-MS |
| CSV/엑셀/복사한 표 — 행=샘플, 열=`175Lu`, `169Tm (KED)` 같은 동위원소 | ICP-MS |
| PDF를 열어 Ctrl+A·Ctrl+C 한 텍스트 (PDF 모듈을 못 불러올 때 대안) | ICP-MS |

PDF 해석 모듈(pdf.js)은 처음 PDF를 넣을 때 인터넷에서 불러옵니다. 오프라인이면 텍스트 붙여넣기를 쓰세요.

#### ICP-OES
1. 샘플 라벨에서 serial·추가희석 n을 자동 추측 → lot 매핑 확인/수정
2. **희석배율 사전입력 토글** — ICP 프로그램에 희석배율을 미리 넣어 결과값에 이미 곱해져 나온 파일이면 On. 파일의 희석/원액 샘플 값 비교로 **자동 감지**됩니다. On이면 농도·수율 계산에 n을 다시 곱하지 않고(×1), n은 ICP lot 명칭(_20k)·총 희석 기록에만 씁니다
3. 원소별 사용 파장 선택 — 기본값은 **유효 실측(플래그 없음·검정범위 내) 샘플 수가 가장 많은** 파장. 칩에 간섭%와 유효 수를 표시
4. 실제 조성(at%)·수율 즉시 계산. 조성 배지 옆 **λ±x%** = 검정범위 안에 든 다른 파장들이 선택 파장과 얼마나 다른지(5% 이하 초록 · 10% 초과 빨강 = 분광 간섭 의심)
5. **4) lot별 통합 결과** — 같은 lot의 기본·추가희석(d) 측정이 함께 있으면 원소마다 *검정범위 안에서 신호가 가장 큰 희석*을 자동 선택해 하나의 조성으로 합칩니다(칩을 눌러 수동 변경). "희석 간 일치"는 두 희석이 모두 범위 안일 때 원액 환산값 차이
6. 저장: 통합 체크 시 그런 lot은 기록 1건, 아니면 측정마다 1건. 같은 측정의 로그북 이관(舊) 기록은 자동 대체(숨김). 총 희석은 실제 aliquot·최종부피로 기록

#### ICP-MS
1. **샘플 고르기** — 라벨의 `500k`, `5M`, `x1/50000` 표기를 **총 희석배수(원액 기준)**로 읽습니다. 표기가 없으면 "희석 표기 없는 라벨" 값, 끝에 `d`가 붙으면 "'d' 붙은 라벨" 값(기본 500k / 5M, 기억됨). 희석 표기가 있거나 지난번 접두어(예: WJ)와 같은 라벨만 기본 포함 — 다른 사람 샘플은 접혀서 바탕선 근거로만 쓰입니다
2. **정량 원소** — lot을 연결하면 lot 양이온(Na·Li·K 제외), 없으면 어느 희석에서든 LoD 이상 검출된 원소. 칩을 눌러 바꾸면 같은 lot의 모든 희석에 적용
3. **측정 품질 점검** — 동위원소마다 R², 검정범위, LoD/LoQ(LoQ = 10σ = 3.33×LoD), 저농도 표준 회수율(보정 전→후), 바탕선 오프셋, 최대 간섭 추정
4. **바탕선(blank) 보정** — 검정용 blank가 실제 무첨가 시료보다 높게 측정되면 절편이 높게 잡혀 *모든 값이 같은 양만큼 낮게*(원소 없는 시료는 음수로) 읽힙니다. 그 원소가 **없는** 측정(조성을 아는 내 샘플 + 다른 시료의 음수 판독)의 중앙값으로 오프셋을 추정해 더합니다. 근거 2개 미만이면 0, 칸에 값을 넣으면 수동값. 보정 후 저농도 표준 회수율이 100%에 가까워지면 타당하다는 독립 증거
5. **판정** — LoD 미만 = 정량 불가(빨강) · LoQ 미만 = 반정량(노랑) · 최저 표준 미만 = 외삽(노랑) · 최고 표준 초과 = 상한 초과(빨강) · RSD > 10%(노랑)
6. **결과** — 같은 lot의 여러 희석 중 원소마다 *가장 좋은 판정 → 그중 신호가 큰* 판독을 자동 선택(칩 클릭으로 변경). 조성 at% ± 2σ(반복 RSD·오프셋 불확도·blank 잡음 LoD/3 전파), 목표 대비 차이(2σ보다 크면 강조), 희석 간 일치, 수율
7. **간섭 추정** — 시료 조성(lot 양이온 몰비)에서 동중원소·MO⁺·MOH⁺·MH⁺·M²⁺·ArM⁺ 후보와 겉보기 기여[%] = (n_X/n_E)·(존재비비)·계수를 계산. 계수 기본값은 사중극자 전형값(MO⁺ 1%, MOH⁺ 0.1%, MH⁺ 10⁻⁵, M²⁺ 2%) — 장비 성능 보고서 값으로 바꿀 수 있음. 같은 원소에서 생기는 것은 표준에도 똑같이 생기므로 제외
8. **결과 표 복사**(엑셀 붙여넣기용) · **저장** — lot마다 ICP 기록 1건(`150c_MS@날짜`, 분석법 ICP-MS, 원소별 사용 희석·동위원소·판정·±2σ 포함)

> Qtegra 주기율표의 "Interferences" 목록은 같은 m/z에 올 수 있는 이온 **후보 전체**이고, Abundance는 그 이온의 동위원소 존재비 곱입니다(간섭 크기 아님). 노란 줄이 목록을 보여주는 동위원소, 파란 토글이 실제 측정 동위원소입니다.

**수동 역산 계산기** — 측정 ppm과 희석 조건에서 원 시료 농도를 거꾸로 계산합니다.

**Out of range**: 기준은 가져온 파일의 표준용액 범위(통상 0.1–5 ppm, 측정 스케일 기준). 상한 초과·음수·하한 미만과 장비 u·o 플래그가 표시되며, Out 원소가 있으면 수율에 ⚠(신뢰도 낮음).

**수율 계산**: 측정 ppm → stock 농도 환산(× final/aliquot × n_eff) → stock 내 mg → ÷ 원자량 = mmol → ÷ (AB × 조성계수) = 원소별 수율, 합산 = 전체 수율.

## ICP 기록

검색(Enter) · 상세 드로어(파장/동위원소·측정값·stock량·수율 내역) · 삭제. 舊 배지 = 로그북 이관 기록, MS 배지 = ICP-MS 기록. 총 희석은 실제 기록값(원소별로 다르면 `×1/500k(Tm·Lu), 5M(Yb)` 형식)으로 표시됩니다.

엑셀 내보내기는 합성 로그 + ICP 로그 + 상세 시트를 출력합니다(TEM 반지름·입자수 농도 열 포함).
